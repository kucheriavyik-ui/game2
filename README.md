# Облога Корвена

Наративна гра про місто в облозі. Ви — Копарікус, Протектор Корвена, якого Король надіслав із печаткою, двомастами Лицарями Тіла і котом на плечі. Шістдесят тисяч вершників на пагорбах, рада, де кожен тягне місто у свій бік, і десять місяців, які треба протриматися. Вид зверху, піксель-арт, grimdark.

Орієнтири: Frostpunk (важкі рішення), Reigns (прості шкали і наслідки), Suzerain (рада з власними інтересами).

## Як грається місяць

1. Картка місяця.
2. Відкриття ради в ратуші: радники доповідають і називають кризу.
3. Ратуша і місто: розмови з радниками, городянами й Лицарями, огляд предметів. Те, що ви дізнаєтесь (**Знання**), відкриває приховані варіанти рішень.
4. Стіл ради: 2–3 рішення, біля кожного варіанта видно, хто з радників «за» і хто «проти».
5. Підсумки: хліб, золото, стіни й порядок, настрій ради. Якщо щось упало до нуля — місто падає.

Написано місяці 1–6. Місяці 1–3 — вичитаний сюжет автора, 4–6 — чернетка.

## Запуск

Потрібен [Node.js](https://nodejs.org) 20 або новіший.

```bash
npm install
npm run dev
```

У Windows PowerShell замість `npm` пишіть `npm.cmd` (`npm.cmd run dev`), бо PowerShell блокує скрипт `npm.ps1`.

Гра відкривається на `http://localhost:5174`.

**Керування:** WASD або стрілки — рух, E — говорити чи оглянути, Space/Enter — далі, 1–4 — вибір відповіді, J — журнал, R — шкали ресурсів, M — музика, Esc — пауза, коліщатко миші — віддалити камеру.

**Для розробки** (лише в `npm run dev`):

| Адреса | Що робить |
|---|---|
| `?month=m04` | одразу в місяць 4, з картки |
| `?month=m04&loc=city` | одразу в місто місяця 4 |
| `?month=m03&loc=city&set=f_spy_marked,k_strait` | те саме з увімкненими змінними сюжету |
| `?new` | стерти збереження |

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | гра з перезавантаженням на льоту |
| `npm run story:check` | перевірка сюжету: усі розмови проходяться, Знання відкривають варіанти, до кожного персонажа можна дійти, шість місяців без поразки |
| `npm run typecheck` | перевірка TypeScript |
| `npm run build` | статичний сайт у `dist/` |
| `npm run artifact` | збірка для публікації як артефакт claude.ai (у `artifact/`) |

## Як улаштовано

Код — це рушій, а світ живе в контенті. Щоб додати місяць, персонажа чи рішення, TypeScript правити не треба.

```
content/
  months/       m01.json …        номер, назва, атмосфера, які knot'и грають
  locations/    townhall, city, tavern, infirmary, guild_office (ASCII-мапа + json)
  characters/   <id>.json         ім'я, посада, портрети
  story/        *.ink             усі діалоги, рішення й стан гри
  journal.json  council.json  resources.json
docs/
  lore.md                         світ, персонажі, таємниці
  story/months_01-03.md           сюжет місяців
assets/                           арт, музика, manifest.json, PROMPTS.md
src/                              рушій (Phaser 3 + TypeScript)
```

- **Діалоги й рішення** — в [Ink](https://www.inklestudios.com/ink/). Увесь стан гри (ресурси, лояльність, Знання, наслідки рішень) — змінні в `content/story/main.ink`.
- **Мапи** — текстові сітки: кожен символ — тайл, легенда і персонажі описані в json поруч.
- **Арт** згенеровано в [PixelLab](https://pixellab.ai); кожен промпт записаний у `assets/PROMPTS.md`. Щоб замінити картинку, досить нового файлу і рядка в `assets/manifest.json`.
- Детальний технічний бриф і журнал рішень — у [`CLAUDE.md`](CLAUDE.md).

## Стек

Phaser 3, TypeScript (strict), Vite, inkjs. Роздільність 480×270 із цілочисельним масштабуванням, тайл 32×32, шрифт Press Start 2P.
